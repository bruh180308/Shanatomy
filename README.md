# Shanatomy v2.0

Bộ ứng dụng hỗ trợ học tập giải phẫu 3D bằng tiếng Việt dành cho Complete Anatomy trên **Windows 10/11 (x64)** và **macOS 11.0+ (Universal: Intel & Apple Silicon M1–M4)**.

Kho lưu trữ này chỉ phục vụ phân phối bộ cài đặt chính thức và tệp kiểm tra cập nhật tự động (`releases/update.json`, `releases/update-macos.json`).

## Tải xuống bản mới nhất

- **Trang phát hành (Windows & macOS):** [GitHub Releases](https://github.com/bruh180308/Shanatomy/releases/latest)
- **Trang chủ & kích hoạt bản quyền:** [https://shanatomy.store/](https://shanatomy.store/)

### Hướng dẫn nhanh trên Windows
1. Cài đặt **Complete Anatomy** từ Microsoft Store.
2. Tải `Shanatomy-Windows.exe` từ mục **Releases**.
3. Mở trực tiếp `Shanatomy-Windows.exe` và nhập key bản quyền để sử dụng.

### Hướng dẫn nhanh trên macOS (Intel & Apple Silicon)
1. Cài đặt **Complete Anatomy** từ Mac App Store.
2. Tải `Shanatomy-MacOS.dmg` (hoặc `Shanatomy-MacOS.zip`) từ mục **Releases**.
3. Kéo **Shanatomy.app** vào thư mục **Applications**.
4. Nếu macOS báo cảnh báo kiểm dịch khi mở lần đầu, hãy chạy tệp **`Mo-Shanatomy-Mac.command`** đi kèm trong gói tải về hoặc dùng lệnh:
   ```bash
   xattr -cr /Applications/Shanatomy.app && open /Applications/Shanatomy.app
   ```
